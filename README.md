# 客舍，第一门以古汉语虚词为语义骨架的Lisp方言

**核心特性**：
- 古汉语虚词形式化语法（若/则/之/者/所/夫/也）   - **编译时无需标点，无需括号，也无需缩进**
- 虚词为原生map，代码即数据
- 为AI原生设计
- 寄生Common Lisp和Clojure，借用其生态
示例：`若等甲1者1也阴也` → `(if (= 甲 1) 1 nil)`
